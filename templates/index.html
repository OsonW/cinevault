Getting a TMDB API Key
1
Create a free account at themoviedb.org
2
Go to Settings → API
3
Click under Request an API Key and choose Yes, This is for my own personal use only
4
Name the application CineVault and use https://localhost for Application URL. Put in your contact info and Subscribe
5
Copy the API Key and paste it here. It's the shorter, 32-character hex string
What is TMDB?
TMDB is a database for movies and TV shows that is required to access, look up, and view media information. As this project is not funded, we do not offer TMDB APIs, and you are required to use your own key.
TMDB offers their own database for TMDB ratings.
Getting an MDBList API Key
1
Create a free account at mdblist.com
2
Click on your username and open your Preferences page
3
Scroll to the API Access section and click New API Key if you don't have one
4
Copy the key and paste it here. The free tier allows 1,000 requests per day
What is MDBList?
MDBList is an aggregator that records IMDb, Letterboxd, Tomatometer, Popcornmeter, Metacritic, and MyAnimeList scores for applicable movies and TV shows.
Note that MDBList calls are Per Title Only meaning that each call retrieves information for a single movie or TV show, regardless of how many pills you choose. You are limited to 1,000 requests per day with the free tier. You can view your usage under filter settings for search or library.
If you do not provide an MDBList key, CineVault will still work, but you will not see scores for movies and TV shows.
